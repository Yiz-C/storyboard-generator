# 三张参考画面的视觉风格总结 + 可复用提示词

> 说明：本分析基于你给的三张画面文字描述完成，未读取图片文件。

## 一、一句话风格定位

**深夜的青蓝冷色底 + 暖橙色发光点 + 近黑剪影 + 极简几何构图 = 冷暖对比强烈的电影感夜景。**

三张图共用同一套视觉语言，可以固化成一条"风格公式"：以后只替换主体内容、其余风格词不动，就能稳定出图。

## 二、风格拆解

### 1. 色彩：固定的三色配方

| 角色 | 颜色 | 用法 |
|---|---|---|
| 底色 | 深青蓝 → 深蓝渐变 | 天空 / 整体环境，占画面大部分，定下"深夜冷调"基调 |
| 剪影 | 近黑的深蓝黑 | 建筑、山体、物体，几乎无细节 |
| 光源 | 暖橙（唯一光源色） | 窗户、路灯、主光、倒影全部同色系，带柔和光晕 |
| （可选）点缀 | 高饱和红 | 画面中唯一的饱和色物体，让焦点"跳出来"（图2 的红球） |

核心记忆点：经典 teal-orange（青橙）电影调色，冷暖对撞是这套风格最有辨识度的地方。

参考色值（供微调，非强制）：
- 天空渐变：#0E2A38（深青蓝）→ #14323F（深蓝）
- 剪影：#07121A
- 暖橙光：亮部 #FFB366，光晕过渡 #FF8C42
- 唯一红点（可选）：#D93A3A

### 2. 光线：少而集中、全部暖色

- 时间感是深夜 / 黄昏后，环境光极弱；
- 画面里往往只有一类光源（路灯、窗户、一束主光），全部偏暖；
- 每个光源都带柔和光晕（glow / bloom），光斑是晕开的、不是硬边；
- 遇到水面或反光面，灯光会拉成**横向光带倒影**（图3）——这是整套风格最具辨识度的细节之一。

### 3. 构图：极简、留白、光比主体更抢眼

- 天空占画面一半以上，大量留白；
- 主体以剪影待在画面下方或远处，位置偏"配角"，光才是主角；
- 明确的单方向主光（图2 是左侧透入）；
- 横构图 16:9 最贴近三张参考的电影感。

### 4. 造型与质感：扁平、干净

- 扁平插画感：干净的色块、平滑的边缘，没有纹理和噪点；
- 物体简化成剪影，只保留轮廓特征（比如楼面上的方形窗洞）；
- 细节密度低，但发光点的分布（散布 / 成组 / 成片）可以当"构图音符"来排。

### 5. 情绪

安静、孤独、空旷的深夜氛围；冷色包裹暖色，暖色像"有人存在过"的信号。

## 四、三张参考对应的现成"场景段"（整段替换【主体内容】）

- **① 城市夜景（图1）**：画面下方是深色建筑剪影，楼面上散布暖橙色方形窗户，其中几扇带光晕，画面中央下方有一片暖橙色路灯光斑。
- **② 室内暗调静物（图2）**：深色桌面位于画面下方，一束柔和暖橙主光从画面左侧透入，桌面右侧放着一只红色的球——画面中唯一的高饱和红色。
- **③ 水面夜景（图3）**：天空与水面相接，远处有三组低矮深色剪影，水面上散布横向拉长的暖橙色灯光倒影。

这三段可以当"零件库"存起来，也可以直接换掉里面的具体物体（建筑→山、桥、人物剪影；红球→任何想突出的物件）。

## 五、可选调钮（风格不变、只调变化）

1. **焦点点缀**：想让某个物体跳出 → 加"画面中唯一的高饱和【颜色】物体"（图2 的红球手法）；不写则保持纯青橙双色。
2. **光位**：加"主光从画面左侧 / 右侧 / 正上方透入"即可改变。
3. **倒影开关**：画面里有水面或光滑地面 → 加"横向拉长的暖橙灯光倒影"。
4. **光晕强度**：想要更朦胧用"强烈光晕"，想要更克制用"微弱光晕"。
5. **介质切换**：把"扁平插画"换成"电影感 CG 渲染"或"low-poly 3D"，色彩与光的配方不变，质感会变。
6. **画幅**：默认 16:9 横构图；竖构图时把天空渐变换成纵向纵深即可。
