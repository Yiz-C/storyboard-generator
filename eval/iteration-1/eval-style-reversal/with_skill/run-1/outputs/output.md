# 视觉风格提炼：暗夜青橙电影风

## 风格分析（简要）

三张参考截图的共同主导风格：

- **色调**：低饱和的深青蓝（teal-cyan）为全片基底，暖橙色是唯一的暖色点缀，构成经典的青橙互补配色（teal-and-orange）。
- **影调**：低调布光（low-key），高反差，大面积深影，细节隐没于黑暗，深色剪影形轮廓映衬在明亮的渐变天空上。
- **饱和度**：整体克制、阴郁；冷色基底深沉低饱和，暖橙光斑相对明亮饱和，形成冷暖对比。
- **光影**：暖色实景光源（practical lights）是画面的视觉焦点，光源均带柔和辉光与光晕（bloom）；截图2进一步显示柔和暖色主光自画面一侧透入。
- **质感**：夜景电影氛围，胶片颗粒，电影级调色，写实风格。

注：截图2中的红球为单张特有元素，不纳入统一风格前缀。
