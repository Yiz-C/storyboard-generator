# 短片《灯塔 · 阿七》分镜脚本（风格版）

> 类型：奇幻 ｜ 主角：阿七，17岁，倔强、好奇 ｜ 输出：静态图像 ｜ 生成工具：Midjourney
> 参考风格：三张截图（深青蓝夜幕 + 暖橙点光，详见下方风格总结）

---

## 一、画面风格总结（三张参考图提炼）

**风格一句话**：青蓝夜幕为底、暖橙点光为魂的 blue hour 电影静帧——大冷小暖、全剪影、带光晕的黄昏奇幻。

| 维度 | 规则 | 依据 |
|---|---|---|
| 主色 | 深青蓝（teal/cyan-blue）承担一切大面：天空渐变、水面、暗部空间。不是死黑，保留微光层次 | 截图1、3的天空 |
| 点缀色 | 暖橙（amber）是唯一光源色：方形窗户、路灯光斑、侧面主光、水面横向光带，全部带柔和光晕（halation） | 截图1、2、3 |
| 例外色 | 高饱和红，全片只出现一处 | 截图2的红球 |
| 形态 | 主体一律深色剪影（建筑、人物、船、远岛），靠轮廓与边缘光（rim light）交代，不靠内部细节 | 截图1、3的剪影 |
| 影调 | 暗部压青蓝、低饱和；高光全归暖橙。经典 teal & orange 调色：冷热强对比 + 过渡柔和 | 三张图一致 |
| 质感 | 动画电影静帧质感（新海诚式天空渐变与光斑），静谧中带不安——奇幻片气质 | 整体观感 |
| 构图 | 水平三段式（天空渐变 / 剪影中景 / 暗部地面水面）；暖光落在 1/3 黄金位；大景小人的空旷感；纯静态，无运动模糊 | 截图1、3的布局 |

**本片风格执行**：红 = 奇幻伏笔色，指定给 **阿七的红围巾 + 塔灯内芯**，每帧至多一处高饱和红；其余一切（灯塔、石阶、船、礁岛、人物）保持青蓝剪影。

---

## 二、空间规划（全片统一场地）

- **场地**：海边断崖，崖顶旧灯塔（石砌、深灰蓝、方形小窗），塔下一条之字形石阶沿崖而下，通到崖底小码头。
- **光源方位**：暖橙光来自海面偏西方向（夕阳余晖 + 塔灯倒影），塔窗朝海。第 1-4 镜光线略亮，第 5-9 镜更深。
- **海面**：远处三组低矮礁岛剪影（呼应截图3）；水面一条暖橙"光路"从远方铺向岸边。
- **船**：无灯黑船从光路远端驶向码头，始终纯黑剪影，船身无任何光点。
- **固定道具**：阿七的红围巾（唯一红色）、塔顶旧灯（暖橙内芯）。

## 六、Midjourney 使用说明

1. **风格锁定**：前三个 prompt 末尾附加三张参考截图作风格参考——`--sref <截图1URL> <截图2URL> <截图3URL> --sw 150`；之后可改引用已生成的满意帧作 sref，保持全片统一。
2. **角色锁定**：正式抽卡前先出一张阿七定妆图（正面 / 侧面 / 背面 + 红围巾），之后每帧追加 `--cref <定妆图URL> --cw 100` 保一致。
3. **画幅**：统一 `--ar 16:9`；若竖屏发行改 `--ar 9:16`。
4. **红色纪律**：每帧最多一处高饱和红（围巾或灯芯）；船、建筑、人物一律青蓝剪影，防止模型加戏。
5. **抽卡标准**：每镜 4 选 1，挑「剪影干净、暖光在 1/3 黄金位、暗部有层次不死黑」的那张。
6. **生成顺序**：第一组（Shot 01-04）已可直接粘贴生成，建议先跑 Shot 01 建立镜头验证风格，再批量出 02-04；定妆图出来后推进第二组。
